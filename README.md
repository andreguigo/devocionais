# Lumina Devocionais

Aplicação web desenvolvida para exibir **devocionais cristãos**.

O projeto apresenta reflexões bíblicas organizadas por temas e sentimentos, permitindo uma leitura rápida e edificante diretamente no dispositivo.

## Objetivo

Este projeto foi criado como experimento de desenvolvimento **frontend com Vue.js**, aplicando a tecnologia para disponibilizar conteúdos devocionais cristãos de forma simples na web.

## Funcionalidade

- Exibição de devocionais
- Interface leve e focada na leitura
